# 《以下犯上》预测模型说明

> 版本 2.0.0 · 2026-11-05 · 可复现：`python3 pipeline/model.py --final`

---

## 一、目标

给定两支战队与赛制，输出**系列赛胜率**。不预测具体比分（比分只做同胜率区间的历史众数展示），不接入赔率。

---

## 二、数据切分（防泄漏）

| 集合 | 时间范围 | 场次 | 用途 |
|---|---|---|---|
| 训练 | 2020-04-26 → 2024-12-31 | 26,818 | 拟合回归系数 |
| 验证 | 2025-01-01 → 2025-12-31 | 3,296 | 选 K 值 / 状态窗口 |
| **测试** | **2026-01-01 → 2026-11-05** | **2,656** | **只测一次，不参与任何选择** |

ELO 按比赛时间顺序滚动更新；每场的特征只使用**该场之前**的信息（评分、状态、交手、休整）。

---

## 三、ELO

- 初始分 1400；新队前 10 场 K 值放大（最多 ×1.6）。
- 基础 K = 30。
- 赛事级别乘数：

| 级别 | 乘数 | 例子 |
|---|---|---|
| 国际大赛 | ×1.90 | Champions、Masters、World Cup |
| VCT 联赛 | ×1.45 | VCT 2026 各赛区联赛、First Strike |
| 挑战者 / 次级 | ×1.00 | Challengers、Ascension、公开预选 |
| 其他 | ×0.60 | 小型第三方赛、表演赛 |

- 比分差乘数：`1 + 0.35 × (min(|比分差|,3) − 1)`，即 2-0 略高于 2-1。
- 跨赛季回归经验证没有提升（验证集 log loss 变差），已关闭（`regress = 1.0`）。

---

## 四、特征

| # | 特征 | 定义 |
|---|---|---|
| 1 | 截距 | — |
| 2 | ELO 差 | `(eloA − eloB) / 400` |
| 3 | 近期状态 | 近 20 场「实际 − 赛前期望」的指数加权均值（半衰期 60 天），A−B，单位 ELO 分 |
| 4 | 交手记录 | 近 3 年双方交手的加权胜率差，映射到 ±40 ELO 分 |
| 5 | 国际大赛 | 是否 Champions/Masters 级别 |
| 6 | Bo5 | 是否五局三胜 |
| 7 | Bo1 | 是否单局 |
| 8 | 低样本修正 | `ELO 差 × (1 − min(1, min(场次A, 场次B)/10))` |
| 9 | 休整差 | `(ln(1+天数A) − ln(1+天数B)) / 4`，天数封顶 365 |

拟合：L2 正则逻辑回归，按样本时间做指数加权（半衰期 730 天）。

### 拟合系数（最终版）

| 项 | 系数 |
|---|---|
| 截距 | +0.159 |
| ELO 差 | **+1.877** |
| 近期状态 | +0.599 |
| 交手记录 | +0.075 |
| 国际大赛 | −0.060 |
| Bo5 | +0.072 |
| Bo1 | −0.001 |
| 低样本修正 | +0.188 |
| 休整差 | −0.497 |

> 说明：交手记录系数很小，意味着在控制 ELO 与状态后，“历史克星”几乎不提供额外信息；休整差为负，表示久疏战阵反而略不利。两项都保留是为了校准，不宜单独解读。

## 五、回测结果

### 总体

| 集合 | 场次 | 命中率 | Log Loss | Brier |
|---|---|---|---|---|
| 训练 | 26,818 | 66.6% | 0.603 | 0.209 |
| 验证 | 3,296 | 63.7% | 0.643 | 0.225 |
| **测试 2026** | **2,656** | **63.3%** | **0.645** | **0.227** |
| 基线：纯 ELO | 2,656 | 61.9% | 0.654 | — |

提升幅度：命中率 **+1.4 个百分点**，log loss **−0.0084**。诚实说，这是“有用但不大”的提升；大部分信息来自 ELO 本身。

### 按赛事级别（2026 测试集）

| 级别 | 场次 | 命中率 | Log Loss |
|---|---|---|---|
| 挑战者 / 次级 | 1,847 | 63.9% | 0.635 |
| VCT 联赛 | 562 | 61.9% | 0.678 |
| 国际大赛 | 110 | 64.5% | 0.628 |

### 校准（2026 测试集）

| 预测区间 | 样本 | 平均预测 | 实际命中 |
|---|---|---|---|
| 0–10% | 3 | 8% | 0% |
| 10–20% | 37 | 16% | 19% |
| 20–30% | 118 | 26% | 25% |
| 30–40% | 259 | 35% | 32% |
| 40–50% | 452 | 46% | 44% |
| 50–60% | 677 | 55% | 56% |
| 60–70% | 550 | 65% | 62% |
| 70–80% | 384 | 74% | 73% |
| 80–90% | 163 | 84% | 76% |
| 90–100% | 13 | 92% | 85% |

**高置信区间偏乐观**（80–90% 档实际 76%），样本也少；因此 App 不把概率当作“稳胆”，置信度标签会额外参考样本量。

## 六、比分展示

比分不是独立模型。做法：把所有历史比赛按“模型预测胜率 × Bo 制式”分箱，统计该箱内**胜方实际比分**的众数。

例如 BO3、预测胜率 70–80% 的历史样本中，2-0 占 71.2%、2-1 占 28.8%，App 就显示 2-0，并标注该比分占比。

这一步使用了全量数据（含测试集）做描述统计，不参与胜率评估。

---

## 七、已知局限

1. **阵容变动**：模型不知道谁离队、谁加盟。2027 赛季前的转会潮会让 ELO 滞后。
2. **地图池 / BP**：没有纳入。地图偏好、永久 ban 位、版本强势图都会影响系列赛。
3. **版本更新**：特工/地图改动带来的系统性变化，ELO 需要若干场才能吸收。
4. **跨赛区可比性**：ELO 是全局单一尺度；赛区之间交手少时，强弱排序会漂移。
5. **样本不足**：新队或低级别队伍前 10 场波动大，App 会向 50% 收缩并标“样本不足”。
6. **不接赔率**：没有市场信息；与博彩公司的定价不可直接比较。
7. **休赛期**：首页焦点对阵是假设推演，不是官方赛程。

## 八、复现

```bash
# 全量网格搜索（K × 状态窗口 × 跨赛季回归）
python3 pipeline/model.py

# 用已保存参数快速重跑（新增比赛后刷新评分）
python3 pipeline/model.py --final

# 产物
data/model.json   # 参数 / 系数 / 指标 / 校准 / 比分分布 / 近期预测
data/elo.json     # 当前评分 / 场次 / 状态 / 最近比赛日
```

测试集指标由 `pipeline/model.py` 直接打印，App 的“模型档案”读的是同一份 `model.json`，不存在两套数字。
